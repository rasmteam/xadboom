System architecture

Three layers, one request path

Every feature in the project document — designer pages, availability badges, cart lock, checkout — lives in exactly one of these layers.

Build workflow

Seven phases from setup to launch

Each phase produces something the next one depends on. Phase 2 comes before the API, the API before the frontend, so every screen is built against real data — no mock swap-over later.

  1. 1

    Scaffold the project

    Create the repository, set up the React frontend build, the Django project with a dedicated apps for designers, assets and orders, and the PostgreSQL connection using environment variables. Establish the shared design-system tokens and component styles for both ends.

    repo & env config React app scaffold Django project + apps PostgreSQL connection
  2. 2

    Model the data in PostgreSQL

    Define Django models and run migrations: designers (resume, honors, philosophy), assets (type categories, materials, dimensions, imagery), limited-run stock counts, the designer↔asset link, users, carts and orders — the inventory-control foundation the document requires.

    models & migrations schema: designers · assets · stock Django admin seeded
  3. 3

    Build the REST API

    Expose endpoints for designer pages, the shop (category and designer filters), and asset pages with real-time stock status. Add authentication and the server-side cart, and deliver structured data for products and designer profiles for SEO.

    Django REST Framework /designers · /assets · /cart · /checkout auth structured data
  4. 4

    Integrate payments and email

    Connect the payment gateway suited to the target region behind a Django service layer, and trigger transactional order-confirmation emails. The checkout endpoint writes the order only after payment is confirmed.

    payment gateway confirmation email callback verification
  5. 5

    Build the React frontend

    Implement the pages against the live API: home page with the approved visual direction, designer pages (bio, honors, asset collection), the shop with category/designer filters, and asset detail pages with availability badges and designer linkage.

    home designer pages shop + filters asset detail + stock badge
  6. 6

    Closing the checkout loop

    Wire cart and checkout end to end. Activate the temporary cart-lock for limited-run items so two buyers cannot claim the same piece, and verify the payment → order → email sequence behaves correctly on failure paths too.

    inventory cart-lock end-to-end checkout flow
  7. 7

    Test, deploy, and respond

    Cover models, API contracts and checkout racing in tests, then deploy the React build and Django services for the initial Iran audience. Monitor stock accuracy and page performance; the B2B trade portal stays on the post-launch roadmap as agreed.

    tests performance deployment B2B portal → later phase
